# MeowID 识别与图片同步

使用现有 `unionOp` 云函数接入 MeowID，保留原独立 `catFace`。支持关闭、独立部署、MeowID 三种识猫模式。

「识猫服务 → 数据同步」显示猫咪的已同步数、剩余数，以及图片的已上传数、剩余数。每组“已同步 / 已上传 + 剩余 = 总数”；注册完成和平台处理中属于已上传的细分状态。结果待核对的图片归入剩余，核对前不会自动重传。

- **全量 / 增量同步**：默认同步全部猫咪档案及审核照片，不限制每猫数量；已有受理记录不重复提交，之前因上限暂缓的照片也会补传。
- **按上限同步**：使用此模块单独保存的每猫图片上限，至少 5 的整数，默认 5。已有 8 张、上限 10 时只补 2 张；审核照片不足 5 张时按实际数量上传。已受理和结果待核对的记录均计入名额，提高上限可补传，降低上限不删除已有图片。

新增照片审核通过后自动上传，不受手动批次上限限制。两种手动同步方式均支持断点继续，均保留原有防重复上传记录。

需部署完整 `functionsEMAS/unionOp/` 并重新编译小程序，不增加云函数或定时器。配置、状态与续传说明见 [接入指南](docs/接入指南.md)，原始接口见 [API 速查](docs/MeowID-API-速查.md)。
