# 喵ID 识猫接入指南

本目录提供可选的 MeowID 后端参考实现。它不改变原项目的识猫入口和页面；接入时仍需适配云函数调用、结果展示和额度提示。

参考实现使用阿里云 EMAS Serverless 的 `ctx.args`、`ctx.mpserverless.db` 和平台登录身份接口，并按猫谱现有数据字段读取猫档案与照片。没有第三方 npm 依赖不等于跨平台可直接部署。迁往其他平台需适配入口、数据库、身份认证、密钥读取和对象存储。

接口说明见 [MeowID 官方文档](https://meowid.net/developers) 和 [图文教程](https://meowid.net/developers/quickstart)。以下步骤适用于已部署 EMAS 版猫谱的维护者。

## 1. 准备账号和服务端配置

MeowID 会接收照片并进行特征提取，登记与识别按量计费。开始前应了解其照片处理方式、服务条款和控制台费用，先用少量照片验证效果。

在 [MeowID 控制台](https://platform.meowid.net) 创建项目，保存项目 ID；它与猫咪个体 ID 不同。创建该项目的 API Key，按用途选择权限：

| 用途 | Scope |
| --- | --- |
| 识别 | `recognition:write` |
| 创建个体和上传参考图 | `cats:write` |
| 同步登记任务 | `tasks:read` |
| 自检、读取个体与注册图片 | `cats:read` |

切换到自定义权限后检查每项勾选。IP 白名单需与云函数实际出口地址匹配；不要在不确定出口地址时填写白名单。

API Key 只保存到服务端，不写入小程序、公开截图或 Git 仓库。本实现从 EMAS 数据库 `app_secret` 集合的一条记录读取配置，不读取环境变量。先创建该记录，再合并以下字段；已有 `OSS_*` 等配置应保留：

```json
{
  "MEOWID_PROJECT_ID": "YOUR_PROJECT_ID",
  "MEOWID_API_KEY": "YOUR_SERVER_API_KEY",
  "MEOWID_TOP_K": 5,
  "MEOWID_ENROLL_IMAGES_PER_CAT": 3,
  "RECOGNIZE_FREE_PER_DAY": 3,
  "RECOGNIZE_AD_BONUS": 2
}
```

| 可选键 | 含义 |
| --- | --- |
| `MEOWID_BASE_URL` | 默认 `https://platform.meowid.net` |
| `MEOWID_THRESHOLD` | −1 到 1；省略或设为空字符串时不向 API 传阈值，采用模型默认值。`0.35` 是官方示例值，需自行测试 |
| `MEOWID_ENROLL_USE_ORIGINAL` | `1` 使用原图；默认使用压缩图 |
| `RECOGNIZE_FREE_PER_DAY` | 每人每天免费次数，默认 3 |
| `RECOGNIZE_AD_BONUS` | 预留广告奖励额度配置；本参考实现禁用 `grantBonus`，配置此值不会启用广告奖励 |

配置在每次调用时读取，修改阈值无需重新部署函数。

## 2. 配置数据和部署云函数

云函数依赖下列 EMAS 集合和字段：

| 集合 | 用途 |
| --- | --- |
| `app_secret` | MeowID 配置；自动建档另需 `OSS_ENDPOINT`、`OSS_BUCKET`、`OSS_SECRET_ID`、`OSS_SECRET_KEY`，用于腾讯云 COS 图片读取 |
| `cat` | 猫档案；绑定与同步会写入 `meowid_id`、`meowid_images` 等字段 |
| `photo` | 自动建档读取 `cat_id`、`verified`、`best`、`photo_id`、`photo_compressed` 等字段 |
| `user` | 以平台登录用户的 OpenID 查找 `manager` 权限 |
| `setting` | 兼容原项目可选识别签名配置 |
| `recognition_log` | 新增集合，保存每用户每天的 `used`、`bonus` 汇总 |

`app_secret` 和 `recognition_log` 应禁止小程序直接读写，仅允许云函数访问。根据 EMAS 当前权限配置方式设置规则，并确认客户端访问被拒绝。

将 `functions/catFace/index.js` 与 `package.json` 放在 zip 根目录，上传到 EMAS 的 `catFace` 云函数并部署。建议内存从 512 MB 起、超时设为 120 秒。识别需要等待推理完成，较短的整体超时可能中断请求；批量建档和诊断仍需控制每批数量。

小程序须先完成 EMAS 的微信登录。云函数从 `ctx.mpserverless.user.getInfo()` 取得调用者身份；匿名调用会被拒绝，客户端传入的 `args.openid` 不会改变调用者身份。管理员权限以平台身份对应的 `user.manager` 判断，不能靠在控制台测试参数中填入管理员 OpenID 获得权限。

## 3. 登记猫咪及绑定本地档案

识别检索的是项目中已经登记的猫咪。只有 Key 而没有完成参考图登记，无法确认猫咪身份。

猫少时可在控制台创建个体、上传参考图，再用已登录管理员调用 `bind`，将云端个体 ID 绑定到本地 `cat.meowid_id`。自动建档则调用 `enrollBatch`：从本地过审照片取图、创建个体并上传参考图。先用小批量确认存储配置和效果。

首次用清晰、光线充足、单猫照片登记，再补充同一只猫的不同角度照片。不要把不同猫的照片放进同一个个体档案。

上传返回 HTTP 202 与 `task_id` 只表示受理。等待任务状态变为 `completed`，再测试识别；`waiting_user` 需选择照片中的目标猫，`failed` 需查看错误后处理。参考实现的 `syncTasks` 可回写最新 100 个任务涉及的最多 200 只猫，更多记录需要扩展分页；未提供选择候选猫、删除个体或重试任务的管理页面。`enrollBatch` 仅选未绑定猫，已绑定但缺少可用参考图的个体需人工补传。请求超时后先查任务，避免直接重复上传。

## 4. 验证后端并适配页面

从已登录小程序通过现有 SDK 调用云函数 `status`。传 `ping: true` 会真实读取 MeowID 个体列表，需要 `cats:read`；配置就绪只说明具备调用条件，不能证明识别效果。

再以管理员身份执行小量诊断：

```json
{"action":"diagnose","limit":1}
```

诊断会读取注册图并调用识别。它不写本地猫档案，却会产生 MeowID 调用与潜在费用；当前实现每只猫最多尝试两次搜索（multipart 和 JSON 对照），且可能超过云函数整体超时。建议限制为一只；不要将它用于定时健康检查。

最后用已登记猫咪的另一张照片调用 `search`，验证本地档案匹配。注意下面两种数据结构不同：MeowID 原始 API 用 `cat_count` 与 `matches`；本参考云函数返回 `catCount`、`unknown`、`candidates`、`recognizeResults` 和 `quota`。原识猫页面仍需转换并展示这些字段。

| 云函数结果 | 页面处理 |
| --- | --- |
| `ok: true`，`catCount: 0` | 提示未检测到猫，不扣本地识别次数 |
| `catCount > 0`，`unknown: true` | 身份未确认；有候选时显示相似猫，不能自动认定 |
| `catCount > 0`，`unknown: false` | 显示绑定的猫档案及相似度 |
| 检测到了但 `recognizeResults` 为空 | 检查云端候选是否已绑定本地档案，给出登记或同步提示 |
| `ok: false` | 展示服务错误或额度不足提示，不能解释成照片没有猫 |

多猫照片应根据每个 `candidates` 项分别展示结果，不能用顶层 `unknown` 代表整张照片。相似度不是识别正确率。

验收至少覆盖已登记猫、无猫照片、未登记猫、额度用完以及匿名或伪造身份请求。`grantBonus` 默认返回 `bonus_not_supported`：客户端广告结束事件不能证明奖励资格；需另行加入服务端真实核验才能开启奖励功能。

## 常见问题与运维

| 现象 | 排查方向 |
| --- | --- |
| 配置未就绪 | `app_secret` 中项目 ID 与 API Key 是否齐全 |
| 401 / 403 | Key 是否有效、所属项目、Scope、IP 白名单 |
| 超时 | 云函数整体超时、服务网络和推理耗时；先查任务再重试登记 |
| 总是身份未确认 | 登记任务是否完成、参考图质量、绑定及阈值 |
| 没检测到猫 | 猫在画面中的尺寸、角度、遮挡及压缩程度 |
| 自动建档下载失败 | COS 配置、照片字段及对象是否存在 |

阈值用不同猫、不同照片的相似度分布校准，不能用一张注册图查自己的高分代表真实识别率。若分布重叠，先补充照片与样本评估，不保证仅调阈值就能区分。

每日额度是应用内部限制，不等于 MeowID 账单上限，也不是并发防刷保证。生产部署应按可信登录身份增加服务端频率和并发限制，并观察第三方平台实际用量。共享给小程序的签名密钥不能代替身份认证或服务端防刷。

`recognition_log` 只存每日汇总，不是每次请求的详细审计日志。如需对账，应另行记录请求 ID、时间和结果，避免记录 API Key 或照片正文。保留本地参考图及个体 ID 映射有助于迁移评估，但本实现未提供向其他模型迁移向量或保持相同识别效果的保证。
